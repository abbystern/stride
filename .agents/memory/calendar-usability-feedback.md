---
name: Calendar usability feedback
description: User-reported first-time athlete feedback motivating explicit calendar planning.
---

A professional athlete using the app for the first time requested explicit
rest-day scheduling and easier calendar-based planning.

**Why:** The user reported this usability-testing feedback as the motivation
for improving the existing calendar.

**How to apply:** Prioritize discoverable rest-day actions and clear
date-based planning when extending the calendar, rather than a disconnected
scheduling system or additional complexity.
